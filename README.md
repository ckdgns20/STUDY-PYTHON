# STUDY-PYTHON

Python 기초 문법과 기본 프로그래밍 개념을 학습하고 정리하는 저장소입니다.
포함된 내용은 다음과 같습니다.

## Learning Goals

- Python 기본 문법 이해
- 입력과 출력 처리
- 변수와 자료형 이해
- 조건문과 반복문을 이용한 프로그램 흐름 제어
- List, Dictionary, Set 등의 자료구조 활용
- 함수 작성 및 활용
- Class와 객체지향 프로그래밍 기초 이해
- 파일 입출력 처리
- 예외 처리
- 작은 Python 프로그램을 직접 설계하고 구현
- NumPy 및 AI·Computer Vision 학습을 위한 Python 기초 역량 확보

## Learning Topics

1. Python Fundamentals
- Python 기본 문법
- 변수
- 자료형
- 연산자
- 입력과 출력
- 형 변환
2. Control Flow
- 조건문
    - if
    - elif
    - else
- 반복문
    - for
    - while
- break
- continue
- 반복문과 조건문의 조합
3. Data Structures
- String
- List
- Tuple
- Dictionary
- Set
- 인덱싱
- 슬라이싱
- 자료구조별 주요 메서드
4. Functions
- 함수 정의
- 매개변수
- 반환값
- 기본값 매개변수
- 여러 값 반환
- 지역 변수와 전역 변수
- 함수 호출 구조
5. Classes & Objects
- 클래스
- 객체
- 인스턴스
- 속성
- 메서드
- __init__
- 객체지향 프로그래밍 기초
6. File I/O
- 파일 읽기
- 파일 쓰기
- with open()
- 텍스트 파일 처리
7. Exception Handling
- 예외의 개념
- try
- except
- else
- finally
- 기본적인 오류 처리
8. Python Modules
- import
- 모듈 사용
- 표준 라이브러리
- 직접 만든 모듈 불러오기
- 패키지 기본 구조
