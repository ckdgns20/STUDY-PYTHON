# 04주차_01 · 함수 기초와 def·호출 15제

## 학습 목표
- `def`로 함수를 정의하고 직접 호출한다.
- 함수 정의와 호출 시점을 구분한다.
- 반복되는 코드를 함수로 묶는다.
- 함수 이름과 들여쓰기의 의미를 익힌다.

## 풀이 규칙
- 1~12번은 `return` 없이 `print()` 중심으로 풉니다.
- 문제마다 별도의 코드 셀 또는 파일 구역을 사용합니다.
- 함수는 정의만 해두지 말고 반드시 호출해 결과를 확인합니다.

# 11번 · 함수 안의 지역 변수 관찰
## 문제

## 입력 예시
입력 없음
## 원하는 출력값
```text
count: 3
```
## 핵심 개념
함수 내부 변수
## 조건·주의사항
scope의 깊은 설명은 다음 세션에서 다루므로, 여기서는 함수 내부에서 만든 변수가 함수 안에서만 쓰인다는 사실만 확인합니다.
