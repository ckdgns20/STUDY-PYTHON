# 04주차_04 · 함수 응용·자료구조 처리 15제

## 학습 목표
- 리스트·딕셔너리·집합을 함수 입력으로 받는다.
- 처리 결과를 새로운 자료구조로 반환한다.
- 입력 데이터가 바뀌어도 재사용 가능한 함수로 작성한다.
- 간단한 연구 데이터 처리 로직을 함수 단위로 분리한다.

## 풀이 규칙
각 문제에서 먼저 아래 4가지를 적고 시작합니다.
1. 함수 입력
2. 함수 내부 처리
3. 반환값 자료형
4. 반환값을 함수 밖에서 어떻게 사용할지

---
# 1번 · 양수만 반환
## 문제
정수 리스트를 받아 양수만 모은 새 리스트를 반환하는 `get_positive(values)` 함수를 작성하세요.
## 입력 예시
```text
-2 0 3 5 -1
```
## 원하는 출력값
```text
[3, 5]
```
## 핵심 개념
리스트 순회, 조건 필터링, 리스트 반환
## 조건·주의사항
원본 리스트는 수정하지 않습니다.

---
