# 04주차_03 · return·다중 반환·scope 15제

## 학습 목표
- `print()`와 `return`을 구분한다.
- 반환값을 변수에 저장해 재사용한다.
- 여러 값을 반환하고 언패킹한다.
- 지역변수와 전역변수의 차이를 이해한다.

## 풀이 규칙
- 가능한 한 결과를 `return`으로 돌려줍니다.
- 함수 안에서 출력만 하고 끝내지 말고 반환값을 함수 밖에서 활용합니다.
- `global`은 문제에서 요구하지 않는 한 사용하지 않습니다.


# 3번 · print와 return 비교
## 문제
`print_double(n)`은 2배 값을 출력하고, `return_double(n)`은 2배 값을 반환하도록 각각 작성하세요. 두 함수의 호출 결과를 변수에 저장해 차이를 확인하세요.
## 입력 예시
`n = 5`
## 원하는 확인
- `print_double(5)`는 화면에 10을 출력하지만 저장값은 `None`
- `return_double(5)`의 저장값은 10
## 핵심 개념
`print()` vs `return`
## 조건·주의사항
두 결과를 각각 변수에 담아 직접 확인합니다.
