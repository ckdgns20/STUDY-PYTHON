# 04주차_02 · 매개변수·인수·기본값 15제

## 학습 목표
- parameter와 argument를 구분한다.
- 위치 인수와 기본값 인수를 사용한다.
- 여러 매개변수를 가진 함수를 작성한다.
- 하드코딩을 줄이고 재사용 가능한 함수로 만든다.

## 풀이 규칙

# 1번 · 이름 출력 함수
## 문제
`show_name(name)` 함수를 정의하고 전달받은 이름을 `이름: 값` 형식으로 출력하세요.
## 입력 예시
```text

```
## 원하는 출력값
```text
이름: 창훈
```
## 핵심 개념
매개변수 1개, 위치 인수
## 조건·주의사항
함수 내부에 이름을 직접 작성하지 않습니다.
