# 02주차_01 · 비교·논리연산자와 조건문 기초 15제

## 학습 목표
- 비교연산자 `>`, `<`, `>=`, `<=`, `==`, `!=`로 조건식을 작성한다.
- `and`, `or`, `not`으로 여러 조건을 결합한다.
- `if`, `elif`, `else`의 실행 순서를 이해한다.
- 조건의 범위가 겹치지 않도록 위에서 아래로 배치한다.
- 중첩 조건문이 필요한 경우와 복합 조건식으로 줄일 수 있는 경우를 구분한다.

> 이번 세션에서는 반복문을 사용하지 않습니다. 모든 문제는 입력 1회와 조건문으로 해결하세요.

# 1번 · 양수, 음수, 0 판별

## 상황
정수 하나를 입력받아 양수인지, 음수인지, 0인지 판별하세요.

## 입력 예시
```text
-7
```

## 원하는 출력값
```text
음수입니다.
```

## 처리 조건
- 0보다 크면 `양수입니다.`
- 0보다 작으면 `음수입니다.`
- 나머지는 `0입니다.`

## 반드시 사용할 개념
- `if`, `elif`, `else`
- 비교연산자

---

# 3번 · 두 수 중 큰 수

## 상황
서로 다른 정수 두 개를 입력받아 더 큰 수를 출력하세요.

## 입력 예시


## 원하는 출력값

# 4번 · 세 수 중 가장 큰 수

## 상황
정수 세 개를 입력받아 가장 큰 수를 출력하세요.

## 입력 예시
```text
17 42 29
```

## 원하는 출력값
```text
최댓값: 42
```

## 해결 방향
- 첫 번째 수가 나머지 두 수보다 모두 큰지 검사합니다.
- 그렇지 않다면 두 번째 수가 세 번째 수보다 큰지 검사합니다.
- 나머지는 세 번째 수가 가장 큽니다.

## 반드시 사용할 개념
- `and`
- `if`, `elif`, `else`

## 제한사항
- `max()`와 정렬은 사용하지 않습니다.

# 6번 · 점수 등급 판정

## 상황
0점 이상 100점 이하의 점수를 입력받아 등급을 출력하세요.

## 등급 기준
- 90점 이상: A
- 80점 이상 90점 미만: B
- 70점 이상 80점 미만: C
- 60점 이상 70점 미만: D
- 60점 미만: F

## 입력 예시
```text
87
```

## 원하는 출력값
```text
등급: B
```

## 핵심 포인트
조건은 높은 점수부터 검사하세요. `score >= 80 and score < 90`처럼 작성할 수도 있지만, 앞에서 90점 이상을 걸러냈다면 `score >= 80`만으로 충분합니다.

# 7번 · 온도 상태 분류


## 원하는 출력값

# 12번 · 윤년 판별 기초

## 상황
연도를 입력받아 윤년인지 평년인지 판별하세요.

## 윤년 규칙
- 400의 배수이면 윤년
- 400의 배수가 아니면서 100의 배수이면 평년
- 그 외에 4의 배수이면 윤년
- 나머지는 평년

## 입력 예시
```text
2024
```

## 원하는 출력값
```text
윤년입니다.
```

## 경계 테스트
- 2000 → 윤년
- 1900 → 평년
- 2024 → 윤년
- 2023 → 평년

## 핵심 포인트
조건 검사 순서가 중요합니다. 4의 배수를 먼저 검사하면 1900을 잘못 윤년으로 판정할 수 있습니다.

# 15번 · 실험 상태 종합 판정

## 상황
실험 정확도, 추론 시간, 오류 발생 여부를 입력받아 최종 상태를 판정하세요.

입력 형식은 다음과 같습니다.

```text
정확도 추론시간 오류여부
```

오류 여부는 `Y` 또는 `N`입니다.

## 판정 기준
1. 오류 여부가 `Y`이면 다른 값과 상관없이 `실험 실패`
2. 오류가 없고 정확도가 95 이상이며 추론 시간이 1.0ms 이하이면 `배포 후보`
3. 오류가 없고 정확도가 90 이상이면 `추가 최적화 필요`
4. 나머지는 `성능 부족`

## 입력 예시
```text
96.8 0.72 N
```

## 원하는 출력값
```text
최종 상태: 배포 후보
```

## 반드시 사용할 개념
- 조건 우선순위
- 문자열과 실수 혼합 입력
- `and`, `if`, `elif`, `else`

## 추가 테스트
```text
98.0 0.50 Y
```
오류가 있으므로 `실험 실패`가 출력되어야 합니다.
