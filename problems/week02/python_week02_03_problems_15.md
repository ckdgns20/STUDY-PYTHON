# 02주차_03 · for와 range 기초 15제

## 학습 목표
for문과 range의 시작값·끝값·간격을 익히고 출력, 누적합, 개수 세기 문제를 연습합니다.

## 풀이 규칙
- while문은 사용하지 않습니다.
- range의 끝값은 포함되지 않는다는 점을 확인합니다.
- 누적 변수는 반복문 전에 초기화합니다.

---

# 1번 · 1부터 N까지 출력

## 문제
정수 N을 입력받아 1부터 N까지 한 줄에 출력하세요.

## 입력 예시
```text
5
```

## 원하는 출력값
```text
1 2 3 4 5
```

## 핵심 개념
- for, range(1, N+1), end

## 조건·주의사항
- N은 1 이상입니다.

---

# 2번 · N부터 1까지 역순 출력


## 원하는 출력값
```text

```

## 핵심 개념
- range(start, stop, step)

## 조건·주의사항
- step은 -1이어야 합니다.
