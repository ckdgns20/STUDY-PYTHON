# 02주차_04 · for와 range 응용 15제

## 학습 목표
중첩 반복문, 탐색, 구간 통계, 패턴 출력, 2차원 데이터 처리를 연습합니다.

## 풀이 규칙
- while문은 사용하지 않습니다.
- 필요한 경우 중첩 for문을 사용합니다.
- 반복 순서를 종이에 표로 추적합니다.

# 1번 · 약수 출력

## 문제

```text

```

## 원하는 출력값

