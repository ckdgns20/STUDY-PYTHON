# 02주차_05 · while 반복문 기초 15제

## 학습 목표
초기값·조건식·증감식을 명확히 구분하고 횟수 기반 반복과 조건 기반 반복을 연습합니다.

## 풀이 규칙
- for문은 사용하지 않습니다.
- 모든 while문에서 변수 변화가 실제로 일어나는지 확인합니다.
- 무한루프가 생기면 조건식과 증감 위치를 먼저 점검합니다.
