# 02주차_06 · while·break·continue 종합 15제

## 학습 목표
반복 종료 조건, 조기 종료, 특정 반복 건너뛰기, 입력 검증과 검색 문제를 종합적으로 연습합니다.

## 풀이 규칙
- break는 반복문 전체 종료, continue는 현재 회차만 건너뜁니다.
- continue 전에 증감이나 다음 입력이 필요한지 확인합니다.
- 무한 반복은 반드시 내부 종료 조건을 가져야 합니다.

---

# 1번 · 0 입력 전 합계
## 문제
정수를 계속 입력받다가 0이 입력되면 종료하고 그전까지의 합을 출력하세요.
## 입력 예시
```text
5
3
-2
0
```
## 원하는 출력값
```text
합계: 6
```
## 핵심 개념
- while True, break
## 조건·주의사항
- 0은 합계에 포함하지 않습니다.

---

# 2번 · 음수 입력 전 개수
## 문제
정수를 계속 입력받다가 음수가 나오면 종료하고 입력된 0 이상의 수 개수를 출력하세요.
## 입력 예시
```text

-1
```
## 원하는 출력값
```text
개수: 3
```
## 핵심 개념
- break, 카운트
## 조건·주의사항
- 종료값인 음수는 세지 않습니다.
