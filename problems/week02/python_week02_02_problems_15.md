# 02주차_02 · 조건문 응용과 복합 판정 15제

## 학습 목표
단순한 한 가지 조건을 넘어 and·or·not, 중첩 if, 경계값, 우선순위가 있는 판정을 연습합니다.

## 풀이 규칙
- 반복문은 사용하지 않습니다.
- 가능하면 조건식을 먼저 한글로 적은 뒤 코드로 옮깁니다.
- 각 문제마다 경계값을 최소 1개 추가로 테스트합니다.

---

# 1번 · 세 수의 중앙값

## 문제
서로 다른 세 정수를 입력받아 가장 큰 수도 가장 작은 수도 아닌 중앙값을 출력하세요.

## 입력 예시
```text
8 3 5
```

## 원하는 출력값
```text
중앙값: 5
```

## 핵심 개념
- 비교연산자, and, if/elif/else

## 조건·주의사항
- 세 수는 서로 다릅니다.

# 2번 · 삼각형 성립 여부

## 문제

## 입력 예시
```text

```

## 원하는 출력값

## 핵심 개념
- 가장 긴 변 < 나머지 두 변의 합

## 조건·주의사항
- 변의 길이는 양수입니다.

# 13번 · 모델 배포 등급

## 문제
정확도, 추론시간(ms), 메모리 사용량(MB)을 입력받아 A·B·배포불가 등급을 판정하세요.

## 입력 예시
```text
98.5 0.8 450
```

## 원하는 출력값
```text
A등급
```

## 핵심 개념
- 복합 조건, 우선순위

## 조건·주의사항
