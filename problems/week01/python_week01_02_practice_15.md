# Python 1주차 연습문제 15제

## 학습 범위

- 변수와 자료형
- `input()`과 `print()`
- `int()`, `float()`, `str()` 형변환
- `split()`과 `map()`
- 산술연산자
- f-string
- 소수점 출력 형식

> 모든 문제는 정답을 보지 않고 직접 작성하세요. 각 문제는 `입력 → 자료형 변환 → 계산 → 출력` 순서로 생각하면 됩니다.

## 1번. 이름 출력하기
사용자의 이름을 입력받아 `안녕하세요, 이름님!` 형식으로 출력하세요.

## 2번. 나이 계산하기
현재 나이를 정수로 입력받아 5년 후 나이를 출력하세요.

## 3번. 정사각형의 넓이
정사각형 한 변의 길이를 정수로 입력받아 넓이를 출력하세요.

## 4번. 섭씨온도 변환
섭씨온도를 실수로 입력받아 화씨온도로 변환하고 소수점 둘째 자리까지 출력하세요.

## 5번. 두 수의 합
한 줄에 정수 두 개를 입력받아 합을 출력하세요. `split()`과 `map()`을 사용하세요.

## 6번. 사칙연산
정수 두 개를 입력받아 덧셈, 뺄셈, 곱셈, 나눗셈 결과를 출력하세요. 나눗셈은 소수점 둘째 자리까지 출력하세요.

## 7번. 직사각형 넓이와 둘레
가로와 세로 길이를 입력받아 넓이와 둘레를 출력하세요.

## 8번. 세 수의 합과 평균
정수 세 개를 입력받아 합과 평균을 출력하세요. 평균은 소수점 둘째 자리까지 출력하세요.

## 9번. 몸무게 변화량
이전 몸무게와 현재 몸무게를 입력받아 변화량을 소수점 첫째 자리까지 출력하세요.

## 10번. BMI 계산
키(cm)와 몸무게(kg)를 입력받아 BMI를 소수점 둘째 자리까지 출력하세요.

## 11번. 할인 가격 계산
상품 가격과 할인율을 입력받아 할인 후 가격을 정수로 출력하세요.

## 12번. 시·분을 분으로 변환
시간과 분을 입력받아 전체 분으로 변환하세요.

## 13번. 시험 점수 평균
국어, 영어, 수학 점수를 입력받아 합계와 평균을 출력하세요. 평균은 소수점 첫째 자리까지 출력하세요.

## 14번. 초 단위 시간 변환
전체 초를 입력받아 시, 분, 초로 변환하세요. `//`와 `%`를 사용하세요.

## 15번. 하루 식사 영양 합계
아침, 점심, 저녁의 칼로리와 단백질을 입력받아 총칼로리와 총단백질을 출력하세요.

## 제출 전 확인표
- [ ] 입력값을 올바른 자료형으로 변환했는가?
- [ ] 여러 값은 `split()` 또는 `map()`으로 처리했는가?
- [ ] 출력 형식이 문제와 정확히 일치하는가?
- [ ] 필요한 경우 f-string을 사용했는가?
- [ ] 소수점 자릿수를 정확히 지정했는가?
