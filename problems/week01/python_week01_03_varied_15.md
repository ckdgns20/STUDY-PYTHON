# 1번 · 연구자 ID 정보 분리

## 상황

연구실에서 사용하는 사용자 ID는 `이름_연도_번호` 형식으로 저장됩니다. 하나의 문자열로 입력된 ID에서 이름, 연도, 번호를 각각 분리해 출력하세요.

## 입력 형식

공백 없이 하나의 문자열이 입력됩니다.

```text
changhun_2026_015
```

## 원하는 출력값

```text
이름: changhun
연도: 2026
번호: 015
```

## 반드시 사용할 개념

- `input()`
- 문자열의 `split('_')`
- 리스트 인덱싱
- f-string

## 제한사항

- `_`의 위치를 직접 세어서 슬라이싱하지 마세요.
- `split()`으로 세 부분을 나누세요.
- 번호의 앞자리 `0`이 유지되어야 하므로 번호를 `int`로 변환하지 마세요.

## 추가 테스트

```text
minji_2025_003
```

# 3번 · 주민번호 형태의 문자열 마스킹


## 원하는 출력값

```text
980101-1******
```

- 문자열 인덱싱
- 문자열 슬라이싱
- 문자열 이어 붙이기

- 입력 문자열의 길이는 항상 14자입니다.
- `replace()`는 사용하지 않습니다.

영상 속 두 좌표의 정확한 가운데 위치를 계산하려고 합니다. 두 점 `(x1, y1)`, `(x2, y2)`를 입력받아 중점을 구하세요.

# 7번 · 영상 해상도 정보 분석

## 상황

영상의 가로 픽셀, 세로 픽셀, 채널 수를 입력받아 전체 픽셀 수와 한 프레임의 원소 수를 계산하세요.

RGB 영상은 픽셀 하나가 3개의 채널 값을 가집니다.


## 반드시 사용할 개념

## 반드시 사용할 개념

# 9번 · 가중평균 성적 계산

## 상황

중간고사, 기말고사, 과제 점수가 서로 다른 비율로 반영됩니다.

- 중간고사: 30%
- 기말고사: 50%
- 과제: 20%

세 점수를 입력받아 최종 점수를 계산하세요.

## 입력 예시

```text
80 90 100
```

## 원하는 출력값

```text
최종 점수: 89.00점
```

## 계산식

```text
최종 점수 = 중간고사 × 0.3 + 기말고사 × 0.5 + 과제 × 0.2
```

## 반드시 사용할 개념

- 가중치 계산
- 실수 연산
- `:.2f`

## 확인할 점

단순 평균 `(80 + 90 + 100) / 3`과 결과가 다르다는 점을 확인하세요.

# 10번 · 이전 값 대비 변화율

## 상황

이전 실험의 정확도와 새로운 실험의 정확도를 입력받아 증가량과 변화율을 계산하세요.

## 입력 예시

```text
84.5 89.2
```

## 원하는 출력값

```text
증가량: 4.70%p
변화율: 5.56%
```

## 계산식

```text
증가량 = 새로운 값 - 이전 값
변화율 = 증가량 / 이전 값 × 100
```

## 반드시 사용할 개념

- 실수 2개 입력
- 퍼센트포인트와 변화율의 차이
- `:.2f`

## 주의사항

`4.70%p`와 `5.56%`는 서로 다른 의미입니다.

# 11번 · 필요한 박스 수 계산

## 상황

제품을 한 박스에 일정 개수씩 포장합니다. 제품 수가 박스 용량으로 정확히 나누어지지 않으면 박스가 하나 더 필요합니다.

조건문 없이 필요한 박스 수를 계산하세요.

## 입력 예시

```text
103 20
```

## 원하는 출력값

```text
필요한 박스 수: 6개
마지막 박스 제품 수: 3개
```

## 계산 아이디어

```text
필요한 박스 수 = (전체 제품 수 + 박스 용량 - 1) // 박스 용량
마지막 박스 제품 수 = 전체 제품 수 % 박스 용량
```

## 반드시 사용할 개념

- 올림 나눗셈
- `//`
- `%`

## 추가 테스트

```text
100 20
```

이 경우 필요한 박스는 5개입니다.

# 13번 · 프레임 번호를 시간 코드로 변환

## 상황

영상의 특정 프레임 번호와 초당 프레임 수(FPS)가 주어집니다. 해당 프레임이 영상의 몇 분 몇 초 지점인지 계산하세요.

## 입력 예시

```text
9050 60
```

## 원하는 출력값

```text
시간 위치: 2분 30.83초
```

## 처리 순서

1. 전체 초를 `프레임 번호 / FPS`로 계산합니다.
2. 전체 초에서 분을 구합니다.
3. 남은 초는 소수점 둘째 자리까지 출력합니다.

## 반드시 사용할 개념

- 실수 나눗셈
- `//`
- `%`
- `:.2f`

## 주의사항

초를 먼저 정수로 바꾸면 `0.83초`가 사라지므로 전체 초는 실수로 유지하세요.

# 14번 · 모델 추론 처리량 비교

## 상황

두 모델의 샘플당 추론 시간(ms)을 입력받아 각각의 초당 처리 가능 샘플 수와 두 모델의 속도 배수를 계산하세요.

## 입력 예시

```text
0.46 1.15
```

## 원하는 출력값

```text
모델 A 처리량: 2173.91 samples/s
모델 B 처리량: 869.57 samples/s
모델 A는 모델 B보다 2.50배 빠릅니다.
```

## 계산식

```text
초당 처리량 = 1000 / 샘플당 추론 시간(ms)
속도 배수 = 모델 B의 추론 시간 / 모델 A의 추론 시간
```

## 반드시 사용할 개념

- 실수 입력
- 역수 개념
- `:.2f`

## 확인할 점

추론 시간이 작을수록 처리량은 커집니다.

# 15번 · 실험 로그 한 줄 요약

## 상황

한 줄에 다음 정보가 입력됩니다.

```text
실험명 학습샘플수 테스트샘플수 정확도 추론시간
```

입력값을 분리하여 전체 샘플 수와 테스트 데이터 비율을 계산하고, 지정된 형식으로 한 줄 요약을 출력하세요.

## 입력 예시

```text
cnn_hist5 8400 2100 98.9 0.46
```

## 원하는 출력값

```text
[cnn_hist5] 전체 10500개 | 테스트 비율 20.0% | 정확도 98.9% | 추론 0.46ms
```

## 처리 순서

1. 입력을 문자열 5개로 나눕니다.
2. 실험명은 문자열로 유지합니다.
3. 학습샘플수와 테스트샘플수는 정수로 변환합니다.
4. 정확도와 추론시간은 실수로 변환합니다.
5. 전체 샘플 수를 계산합니다.
6. 테스트 데이터 비율을 계산합니다.
7. 지정된 형식으로 한 줄에 출력합니다.

## 반드시 사용할 개념

- 혼합 자료형 입력
- 개별 형변환
- 합계와 비율 계산
- 여러 값을 포함한 f-string
- `:.1f`, `:.2f`

## 제한사항

- 모든 값을 `float` 또는 `int`로 한꺼번에 변환할 수 없는 이유를 생각해 보세요.
- 실험명은 숫자로 변환하지 않습니다.
