# 01주차_02 · Python 입출력·형변환 심화 15제

## 학습 목표

- `input()`, `split()`, `map()`, 형변환, 산술연산, f-string을 여러 단계로 조합한다.
- 한 문제에서 중간 계산값을 2개 이상 변수에 저장한다.
- 출력 형식을 공백, 단위, 소수점 자릿수까지 정확히 맞춘다.
- `if`, `for`, `while`, 리스트는 사용하지 않는다.

---

## 1번 · 총 결제금액 계산

**문제**: 상품 단가, 수량, 배송비를 한 줄에 정수로 입력받아 상품금액, 배송비, 총 결제금액을 출력하세요.

**입력 예시**

```text
12500 3 3000
```

**원하는 출력값**

```text
상품금액: 37500원
배송비: 3000원
총 결제금액: 40500원
```

**반드시 사용할 개념**

- `map(int, input().split())`
- 중간 계산값 변수
- f-string

---

## 2번 · 평균 속력 계산

**문제**: 이동 거리(km)와 이동 시간(분)을 실수로 입력받아 평균 속력을 km/h로 출력하세요.

**입력 예시**

```text
12.5 50
```

**원하는 출력값**

```text
평균 속력: 15.00km/h
```

**계산식**

```text
시간(h) = 시간(분) / 60
평균 속력 = 거리 / 시간(h)
```

**반드시 사용할 개념**

- `map(float, input().split())`
- 분을 시간으로 변환
- `:.2f`

**문제**: 반지름과 높이를 실수로 입력받아 원기둥 부피를 계산하세요. 원주율은 `3.14159`를 사용합니다.

**입력 예시**

```text
3 10
```

**원하는 출력값**

```text
원기둥 부피: 282.74
```

**반드시 사용할 개념**

- 실수 입력
- 거듭제곱 `**`
- 상수 변수
- `:.2f`

## 8번 · 온도 두 단계 변환

**문제**: 섭씨온도를 입력받아 화씨와 절대온도(K)를 모두 출력하세요.

**입력 예시**

```text
25.5
```

**원하는 출력값**

```text
화씨: 77.90°F
절대온도: 298.65K
```

**계산식**

```text
화씨 = 섭씨 × 1.8 + 32
절대온도 = 섭씨 + 273.15
```

**반드시 사용할 개념**

- 실수 입력
- 계산 결과 두 개
- `:.2f`

## 13번 · 연료비 계산

**문제**: 이동 거리(km), 연비(km/L), 리터당 가격(원)을 입력받아 필요한 연료량과 예상 연료비를 계산하세요.

**입력 예시**

```text
320 14.5 1680
```

**원하는 출력값**

```text
필요 연료: 22.07L
예상 연료비: 37076원
```

**계산식**

```text
필요 연료 = 이동 거리 / 연비
연료비 = 필요 연료 × 리터당 가격
```

**반드시 사용할 개념**

- 실수 계산
- `:.2f`
- 최종 금액 정수 출력

## 14번 · 원금과 단리 이자

**문제**: 원금, 연이율(%), 기간(개월)을 입력받아 단리 이자와 만기 금액을 출력하세요.

**입력 예시**

```text
3000000 4.5 8
```

**원하는 출력값**

```text
이자: 90000원
만기 금액: 3090000원
```

**계산식**

```text
기간(년) = 개월 / 12
이자 = 원금 × 연이율 / 100 × 기간(년)
```

**반드시 사용할 개념**

- 정수와 실수 혼합 입력
- 월을 년으로 변환
- 계산 순서

## 15번 · 연구 데이터 처리 시간 예측

**문제**: 영상 수, 영상당 프레임 수, 초당 처리 프레임 수를 입력받아 전체 프레임 수와 예상 처리 시간을 시·분·초로 출력하세요.

**입력 예시**

```text
12 18000 75
```

**원하는 출력값**

```text
전체 프레임: 216000
예상 처리 시간: 0시간 48분 0초
```

**계산식**

```text
전체 프레임 = 영상 수 × 영상당 프레임 수
전체 처리 초 = 전체 프레임 / 초당 처리 프레임 수
```

**반드시 사용할 개념**

- 곱셈과 나눗셈
- 처리 초를 정수로 변환
- `//`, `%`
- 중간 변수 4개 이상

## 풀이 규칙

- 문제마다 별도의 코드 셀 또는 `.py` 파일을 사용합니다.
- 출력값의 글자, 단위, 공백, 소수점 자릿수를 정확히 맞춥니다.
- 변수 이름을 의미 있게 작성합니다.
- 내장 함수 이름인 `sum`, `list`, `str`, `input`을 변수 이름으로 사용하지 않습니다.
