# 03주차_03 · 튜플·집합 15제

## 학습 목표
튜플의 불변성·언패킹과 집합의 중복 제거·멤버십 검사·합집합·교집합·차집합을 연습합니다.

---
## 1번 · 좌표 튜플 생성
### 문제
x와 y를 입력받아 `(x, y)` 형태의 튜플로 저장하고 출력하세요.
### 입력 예시
`3 7`
### 원하는 출력값
`(3, 7)`
### 핵심 개념
튜플 생성
### 조건·주의사항
정수로 저장하세요.

---
## 2번 · 튜플 인덱싱
### 문제
튜플 `(10, 20, 30, 40)`에서 첫 값과 마지막 값을 출력하세요.
### 원하는 출력값
`첫 값: 10`
`마지막 값: 40`
### 핵심 개념
튜플 인덱싱
### 조건·주의사항
리스트와 동일하게 음수 인덱스를 사용할 수 있습니다.

---
## 3번 · 튜플 언패킹
### 문제
`point = (12, 5)`를 `x, y`로 언패킹한 뒤 각각 출력하세요.
### 원하는 출력값
`x: 12`
`y: 5`
### 핵심 개념
튜플 언패킹
### 조건·주의사항
변수 개수와 튜플 원소 개수가 맞아야 합니다.

---
## 4번 · 두 변수 값 교환
### 문제
두 정수 a, b를 입력받고 튜플 언패킹 방식으로 값을 교환하세요.
### 입력 예시
`3 8`
### 원하는 출력값
`a: 8`
`b: 3`
### 핵심 개념
`a, b = b, a`
### 조건·주의사항
임시 변수는 사용하지 않습니다.

---
## 5번 · 튜플 불변성 확인
### 문제
`t = (1,2,3)`에서 `t[1] = 99`를 시도했을 때 왜 오류가 나는지 주석으로 설명하고, 수정이 필요하다면 리스트로 변환하여 값을 바꾼 뒤 다시 튜플로 변환하세요.
### 원하는 출력값
`(1, 99, 3)`
### 핵심 개념
튜플 불변성, 형변환
### 조건·주의사항
오류 메시지만 보는 것이 아니라 원인을 설명하세요.

---
## 6번 · 중복 제거
### 문제
정수 리스트의 중복 값을 제거해 집합으로 출력하세요.
### 입력 예시
`1 2 2 3 3 3 4`
### 원하는 출력값 예시
`{1, 2, 3, 4}`
### 핵심 개념
`set()`
### 조건·주의사항
집합은 출력 순서를 보장하지 않습니다.

---
## 7번 · 고유 클래스 개수
### 문제
클래스 라벨 목록에서 서로 다른 클래스의 개수를 출력하세요.
### 입력 예시
`normal fault normal high fault low`
### 원하는 출력값
`고유 클래스 수: 4`
### 핵심 개념
`set`, `len()`
### 조건·주의사항
대소문자는 구분한다고 가정합니다.

---
## 8번 · 집합에 값 존재 여부
### 문제
첫 줄의 집합 데이터에 둘째 줄 값이 존재하는지 출력하세요.
### 입력 예시
`3 5 7 9`
`7`
### 원하는 출력값
`존재함`
### 핵심 개념
`in`
### 조건·주의사항
없으면 `없음`을 출력하세요.

---
## 9번 · 합집합
### 문제
두 정수 집합 A와 B의 합집합을 출력하세요.
### 입력 예시
`1 2 3 4`
`3 4 5 6`
### 원하는 출력값 예시
`{1, 2, 3, 4, 5, 6}`
### 핵심 개념
`A | B`, `union()`
### 조건·주의사항
둘 중 한 방법을 사용하세요.

---
## 10번 · 교집합
### 문제
두 집합에 공통으로 존재하는 값만 출력하세요.
### 입력 예시
`1 2 3 4`
`3 4 5 6`
### 원하는 출력값 예시
`{3, 4}`
### 핵심 개념
`A & B`, `intersection()`
### 조건·주의사항
공통값이 없으면 빈 집합이 됩니다.

---
## 11번 · 차집합
### 문제
A에는 있지만 B에는 없는 값만 출력하세요.
### 입력 예시
`1 2 3 4`
`3 4 5 6`
### 원하는 출력값 예시
`{1, 2}`
### 핵심 개념
`A - B`
### 조건·주의사항
B-A와 결과가 다릅니다.

---
## 12번 · 대칭차집합
### 문제
두 집합 중 한쪽에만 존재하는 값들을 출력하세요.
### 입력 예시
`1 2 3 4`
`3 4 5 6`
### 원하는 출력값 예시
`{1, 2, 5, 6}`
### 핵심 개념
`A ^ B`
### 조건·주의사항
교집합은 제외됩니다.

---
## 13번 · 학습/테스트 클래스 비교
### 문제
학습 데이터 클래스와 테스트 데이터 클래스를 각각 집합으로 입력받아 테스트에만 존재하는 클래스를 출력하세요.
### 입력 예시
`normal low high`
`normal low high fault`
### 원하는 출력값 예시
`테스트 전용 클래스: {'fault'}`
### 핵심 개념
차집합
### 조건·주의사항
출력 순서는 달라도 됩니다.

---
## 14번 · 불량 ID 중복 제거
### 문제
검사 과정에서 기록된 불량 제품 ID 목록에서 중복을 제거하고 고유 불량 제품 수를 출력하세요.
### 입력 예시
`A01 A03 A01 A07 A03 A09`
### 원하는 출력값
`고유 불량 수: 4`
### 핵심 개념
집합 중복 제거
### 조건·주의사항
문자열 ID를 그대로 사용합니다.

---
## 15번 · 연구 데이터 세트 비교
### 문제
실험 A에서 검출된 프레임 인덱스와 실험 B에서 검출된 프레임 인덱스를 각각 집합으로 입력받아 ① 둘 다 검출된 프레임 ② A에서만 검출된 프레임 ③ 전체 검출 프레임을 출력하세요.
### 입력 예시
`10 20 30 40`
`20 30 50`
### 원하는 출력값 예시
`공통: {20, 30}`
`A만: {10, 40}`
`전체: {10, 20, 30, 40, 50}`
### 핵심 개념
교집합·차집합·합집합
### 조건·주의사항
집합 출력 순서는 채점 기준에서 고려하지 않습니다.

## 완료 기준
- 튜플과 리스트의 차이를 설명한다.
- 언패킹을 사용할 수 있다.
- 합집합·교집합·차집합의 의미를 실제 데이터 상황에 연결한다.
